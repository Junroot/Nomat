## ADDED Requirements

### Requirement: 라운드 오디오는 전역 볼륨 설정을 따르며 어떤 라운드 전이도 그 값을 되돌리지 않는다

라운드 오디오 플레이어는 재생 볼륨을 **`playback-volume`의 전역 설정에서 가져와야(SHALL) 하며**, 자체 볼륨 상수를 가져서는 안 된다(SHALL NOT).

플레이어를 방 세션 동안 재사용하고 라운드마다 두 플레이어가 역할을 교대하므로, 볼륨은 **재생 담당 여부와 무관하게 두 플레이어 모두에** 적용되어야(SHALL) 한다. 한쪽에만 적용하면 교대 뒤의 라운드에서 다른 값으로 들린다.

다음 어느 시점에도 사용자가 정한 볼륨이 **기본값이나 다른 값으로 되돌아가서는 안 된다(SHALL NOT):**

- 플레이어 준비 완료(부트스트랩) 시
- 라운드 교대로 담당 플레이어가 바뀔 때
- 정답 공개 구간의 정답 곡 재재생 시
- 선버퍼링 플레이어가 담당이 되어 플레이어 수준 음소거를 해제할 때

선버퍼링 중인 플레이어를 **플레이어 수준에서 음소거하는 기존 요구**("선버퍼링된 트랙은 소리를 내서는 안 된다")는 그대로 유지된다. 그 음소거와 전역 볼륨은 서로 독립이다 — 볼륨을 바꿔도 선버퍼링 쪽의 음소거가 풀려서는 안 되며(SHALL NOT), 담당이 되어 음소거를 풀 때 볼륨은 전역 설정값이어야(SHALL) 한다.

볼륨 변경은 재생 중인 클립에 **즉시** 반영되어야(SHALL) 하며, 재생 위치·반복 카운터·재생 불가 판정에 영향을 주어서는 안 된다(SHALL NOT). 볼륨 0은 재생 불가가 아니다 — 판정은 볼륨과 무관하게 재생 개시 관찰로만 이뤄진다.

#### Scenario: 라운드가 교대돼도 볼륨이 유지된다
- **WHEN** 볼륨을 20으로 정한 뒤 라운드 1이 끝나고 라운드 2가 열려 담당 플레이어가 바뀜
- **THEN** 라운드 2의 클립이 볼륨 20으로 재생되어야 한다

#### Scenario: 정답 공개 재재생도 설정 볼륨을 따른다
- **WHEN** 볼륨이 20인 상태에서 라운드가 `REVEAL`로 전이되어 정답 곡이 다시 재생됨
- **THEN** 재재생이 볼륨 20으로 들려야 한다

#### Scenario: 선버퍼링 플레이어의 음소거는 볼륨 변경에 풀리지 않는다
- **WHEN** `REVEAL` 구간에 다음 곡이 선버퍼링 중일 때 볼륨을 바꿈
- **THEN** 다음 곡의 소리가 나지 않아야 한다
- **AND** 정답 곡의 소리 크기만 바뀌어야 한다

#### Scenario: 재생 중 볼륨 변경이 라운드 상태를 건드리지 않는다
- **WHEN** `OPEN` 구간에 클립이 반복 재생 중일 때 볼륨을 여러 번 바꿈
- **THEN** 재생 위치가 되돌아가거나 반복 횟수가 달라지지 않아야 한다
- **AND** 재생 불가 안내가 표시되지 않아야 한다

#### Scenario: 볼륨 0에서도 재생 불가로 판정하지 않는다
- **WHEN** 볼륨이 0인 상태에서 라운드가 열려 클립이 정상적으로 재생 개시됨
- **THEN** 재생 불가 안내가 표시되지 않아야 한다
